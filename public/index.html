Create a Spotify app

Spotify uses an app registration for login. It takes about a minute and needs no publishing.

  1. Open the Spotify Developer Dashboard and choose Create app.
  2. Set Website to http://127.0.0.1:8888 and add this exact Redirect URI:
    http://127.0.0.1:8888/auth/callback
  3. Under Which API/SDKs are you planning to use?, check Web API only — not Ads API, Web Playback SDK, iOS, or Android.

Keep the app in Development Mode — the account that owns it always has access.

2

Connect your account

Paste the Client ID from your app's settings. Read-only library access is requested by default; changes are opt-in after connecting.

Using the Client ID from .env

Default scope: user-library-read. Write access (user-library-modify) is only requested if you enable changes after connecting. Spotify handles the login; this app never sees your password.

How the comparison works

Missing liked songs: every track in every album you've saved is compared with your Liked Songs by Spotify track ID. Album tracks that aren't in Liked Songs are listed.

Unliked albums: for each of your liked songs, the song's album is checked against your saved albums. If the album isn't saved, it's listed with the liked songs it contains.

Different releases of the same recording have different track IDs on Spotify, so a live version or a greatest-hits copy counts separately from the studio track.
